# Claude Pro — Code Functionality Research

## Question
Does Claude Pro have code functionality?

## Answer
Yes. Claude Pro ($20/month) includes robust coding capabilities through two channels.

## 1. Claude.ai Chat Interface
- Code generation, debugging, review, and explanation across many languages
- Extended thinking mode for complex multi-step reasoning
- 200K–1M token context windows capable of processing entire codebases
- Strong performance on coding benchmarks (77.2% SWE-bench score)

## 2. Claude Code (Bundled with Pro)
Claude Code is an agentic coding tool included in the Pro subscription:
- **Terminal-native**: Install via Homebrew or curl, invoke with `claude` in any project directory
- **IDE extensions**: VS Code, Cursor, Windsurf, JetBrains with inline diffs and conversation history
- **Browser-based option**: Run Claude Code in the browser with no local setup
- **Agentic capabilities**: Reads codebases, edits files, runs shell commands, creates git commits, opens PRs
- **Git integration**: Automated staging, commits, branching, and PR creation
- **CI/CD automation**: GitHub Actions and GitLab CI/CD integration
- **MCP support**: Connect to external tools (Jira, Slack, Google Drive, custom tooling)
- **CLAUDE.md configuration**: Project-level coding standards and preferences

## Usage & Limits
- Usage limits are shared between claude.ai and Claude Code on the Pro plan
- Limits reset every five hours (session-based) with a weekly cap
- For heavier usage: Max plan ($100–$200/month) or API (pay-per-token)
- Estimated Pro plan value: ~$150/month equivalent in API usage

## Key Models Available
- Claude Sonnet 4.5
- Claude Opus 4.5
- Claude Opus 4.6 (latest, with Agent Teams support)
